# Prototype

Primo prototipo statico di Allergy Log.

## Come provarlo

Apri `prototype/index.html` in un browser.

Il prototipo salva i dati nel browser tramite `localStorage`.

## Funzioni incluse

- registrazione giornaliera in due passaggi;
- pulsante `Nessun sintomo`;
- campi obbligatori;
- modifica registrazioni esistenti;
- eliminazione registrazioni;
- calendario mensile;
- grafico ultimi 30 giorni registrati;
- export CSV;
- export JSON;
- import JSON.

## Limite principale

I dati restano nel browser usato per compilare il diario. Per non perderli, esportare periodicamente un backup JSON.
